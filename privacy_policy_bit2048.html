01// 개요

hopalt(이하 "개발자")이 제공하는 Bit 2048(이하 "앱")은 사용자의 개인정보 보호를 중요하게 생각합니다.

> 본 앱은 회원가입, 로그인, 계정 시스템이 없습니다.
> 게임 데이터(점수, 통계)는 기기 내부에 저장됩니다.
> 글로벌 리더보드 기능을 위해 일부 데이터가 서버에 저장됩니다.
> Android 앱에는 지역에 따라 카카오 AdFit(한국) 또는 AppLovin(해외) 배너 광고가 표시됩니다.
> 사용자는 언제든지 자신의 데이터를 삭제 요청할 수 있습니다.
02// 수집 데이터 현황
주체 수집 항목 목적 저장 위치
개발자 (직접)NEW 기기 고유 ID, 닉네임, 국가 코드, 최고 점수, 달성 페이즈 글로벌 리더보드 운영 Google Firebase 서버
기기 로컬 저장 점수, 게임 통계, 현재 페이즈 게임 진행 저장 사용자 기기
카카오 AdFitNEW 광고 ID(GAID), 기기 정보, 광고 상호작용 데이터 한국 지역 배너 광고 제공 카카오 서버
AppLovin MAXNEW 광고 ID(GAID), 기기 정보, 대략적 위치(IP), 광고 상호작용 데이터 한국 외 지역 배너 광고 제공 AppLovin 서버
03// 개발자가 직접 수집하는 데이터 NEW

글로벌 리더보드 기능 제공을 위해 아래 데이터를 Google Firebase Firestore에 저장합니다.

  • 기기 고유 ID — 앱 설치 시 랜덤 생성되는 UUID. 실제 기기 정보와 무관하며 개인을 직접 식별할 수 없습니다.
  • 닉네임 — 자동 생성(예: Bit_KR_7749) 또는 사용자가 직접 설정. 최초 1회만 변경 가능합니다.
  • 국가 코드 — 기기 언어/지역 설정 기반으로 자동 감지 (예: KR, US, JP)
  • 최고 점수 및 달성 페이즈 — 게임 종료 시 자동 저장
ℹ 기기 고유 ID는 앱을 삭제하거나 기기를 변경하면 초기화됩니다.
새로운 ID로 새로운 리더보드 기록이 생성됩니다.

보관 기간

  • 사용자가 앱 내 삭제 요청 시 즉시 삭제
  • 마지막 점수 갱신 후 1년 이상 미활동 시 자동 삭제 (예정)

데이터 삭제 방법

> 앱 실행 → 하단 [ SETTINGS ] 버튼
> → DATA & PRIVACY 섹션
> → [ DELETE MY DATA ] 버튼
> → 확인 시 Firebase 기록 및 로컬 데이터 즉시 삭제
04// Google Firebase

본 앱은 Google LLC가 제공하는 Firebase Firestore를 데이터 저장 서비스로 사용합니다.

  • 저장된 데이터는 Google 클라우드 서버에 암호화되어 보관됩니다.
  • 리더보드에 표시되는 데이터(닉네임, 국가, 점수)는 모든 사용자에게 공개됩니다.
  • 기기 고유 ID는 리더보드에 표시되지 않습니다.
Google Firebase 개인정보처리방침:
https://firebase.google.com/support/privacy
05// 광고 서비스 (Android)

본 Android 앱은 기기의 지역(locale) 설정에 따라 아래 광고 서비스 중 하나를 사용합니다.

  • 한국(KR): 카카오(주) AdFit
  • 한국 외: AppLovin MAX

각 광고 SDK는 광고 표시·최적화를 위해 아래 데이터를 수집할 수 있습니다.

  • 광고 식별자 (Android: GAID)
  • 기기 모델, OS 버전 등 기기 정보
  • IP 주소 기반의 대략적인 위치 정보 (AppLovin)
  • 광고 클릭, 노출 등 광고 상호작용 데이터
이 데이터는 개발자가 아닌 각 광고 사업자가 직접 수집·관리합니다.
카카오 개인정보처리방침:
https://www.kakao.com/policy/privacy
AppLovin 개인정보처리방침:
https://www.applovin.com/privacy/

광고 개인화 설정 방법

  • Android: 설정 → Google → 광고 → 광고 ID 재설정 또는 개인화 해제
  • AppLovin: AppLovin Privacy Portal에서 관련 설정 확인

01// OVERVIEW

hopalt ("Developer") built Bit 2048 ("App") with your privacy in mind.

> This app has NO account system, NO login, NO registration.
> Local game data (score, stats) is stored on your device only.
> Some data is stored on our server for the global leaderboard feature.
> The Android app shows banner ads via Kakao AdFit (Korea) or AppLovin (other regions), based on device locale.
> You can delete your data at any time from within the app.

03// DATA WE COLLECT DIRECTLY NEW

To operate the global leaderboard, we store the following data in Google Firebase Firestore:

  • Device ID — A randomly generated UUID created at first launch. Not linked to your real identity or device hardware.
  • Nickname — Auto-generated (e.g. Bit_KR_7749) or user-defined. Can only be changed once.
  • Country Code — Auto-detected from device locale (e.g. KR, US, JP)
  • Best Score & Phase — Automatically submitted when a game ends
ℹ Your Device ID resets if you uninstall the app or switch devices.
A new ID and new leaderboard record will be created.

Retention Period

  • Deleted immediately upon user request via in-app deletion
  • Auto-deleted after 1 year of inactivity (planned)

How to Delete Your Data

> Open app → [ SETTINGS ] button
> → DATA & PRIVACY section
> → [ DELETE MY DATA ] button
> → Confirm to permanently delete Firebase record and local data
04// GOOGLE FIREBASE

This app uses Google Firebase Firestore (by Google LLC) for leaderboard data storage.

  • Data is stored encrypted on Google Cloud servers.
  • Leaderboard data (nickname, country, score) is visible to all users.
  • Device ID is never displayed on the leaderboard.
Google Firebase Privacy Policy:
https://firebase.google.com/support/privacy
05// ADVERTISING (ANDROID)

This Android app uses one of the following ad services based on your device locale (region):

  • Korea (KR): AdFit by Kakao Corp.
  • Outside Korea: AppLovin MAX

Each ad SDK may collect the following for ad delivery and optimization:

  • Advertising identifier (Android: GAID)
  • Device model, OS version, and other device info
  • Approximate location based on IP address (AppLovin)
  • Ad interaction data (clicks, impressions)
This data is collected by each ad provider directly, not the Developer.
Kakao Privacy Policy:
https://www.kakao.com/policy/privacy
AppLovin Privacy Policy:
https://www.applovin.com/privacy/

Opt out of ad personalization:

  • Android: Settings → Google → Ads → Reset advertising ID or opt out of personalization
  • AppLovin: see the AppLovin Privacy Portal
