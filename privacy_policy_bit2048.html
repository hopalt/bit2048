01 // 개요

hopalt(이하 "개발자")이 제공하는 Bit 2048(이하 "앱")은 사용자의 개인정보 보호를 매우 중요하게 생각합니다.

> 본 앱은 회원가입, 로그인, 계정 시스템이 없습니다.
> 개발자가 직접 수집하거나 서버로 전송하는 개인정보는 없습니다.
> 모든 게임 데이터(점수, 통계)는 사용자 기기에만 저장됩니다.

다만 앱에 탑재된 광고 서비스(Google AdMob)가 광고 제공 목적으로 일부 데이터를 수집할 수 있습니다. 본 방침은 그 내용을 투명하게 안내합니다.

03 // Google AdMob 광고 서비스

본 앱은 Google LLC가 제공하는 Google AdMob 광고 서비스를 사용합니다. AdMob은 광고 표시 및 최적화를 위해 아래 데이터를 수집할 수 있습니다.

  • 광고 식별자 (Android: GAID, iOS: IDFA)
  • 기기 모델, OS 버전 등 기기 정보
  • IP 주소 기반의 대략적인 위치 정보
  • 광고 클릭, 노출 등 광고 상호작용 데이터
  • 앱 사용 패턴 (광고 최적화 목적)
⚠ 이 데이터는 개발자가 아닌 Google이 직접 수집·관리합니다.
Google의 개인정보처리방침:
https://policies.google.com/privacy
AdMob 파트너 정책:
https://support.google.com/admob/answer/6128543
04 // 광고 개인화 설정

사용자는 아래 방법으로 광고 개인화를 제한할 수 있습니다.

  • Android: 설정 → Google → 광고 → 광고 ID 재설정 또는 광고 개인화 선택 해제
  • iOS: 설정 → 개인정보 보호 → 추적 → 앱이 추적을 요청하도록 허용 비활성화
  • Google 광고 설정: adssettings.google.com
05 // 기기 내 데이터 저장

게임 진행 데이터(최고 점수, 게임 통계, 현재 페이즈)는 오직 사용자의 기기에만 저장됩니다.

  • 외부 서버 전송 없음
  • 개발자가 해당 데이터에 접근 불가
  • 앱 삭제 시 모든 로컬 데이터 완전 삭제
06 // 아동 개인정보 보호

본 앱은 만 14세 미만 아동을 대상으로 하지 않습니다. 개발자는 아동의 개인정보를 의도적으로 수집하지 않습니다. 보호자가 자녀가 앱을 사용 중임을 인지한 경우 아래 연락처로 문의하시기 바랍니다.
